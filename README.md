# CPR Holoprint

تطبيق Flutter لأندرويد يوفّر واجهة CPR لإدارة عملية إنشاء حزم HoloPrint لهياكل Minecraft Bedrock.

## الحالة التقنية الحالية

هذه النسخة تستخدم محرك HoloPrint الرسمي من خلال WebView على الرابط:

- https://holoprint-mc.github.io/

الموقع الأصلي يدعم استيراد ملفات `.mcstructure`، واستخراج الهياكل من ملفات `.mcworld` و`.mctemplate` و`.zip`، وتحديث حزم Structura/HoloPrint القديمة، ثم إنشاء حزمة `.mcpack` مع خيارات تخصيص متعددة.

**مهم:** محرك التحويل في هذه النسخة يعمل عبر الإنترنت ولا يعمل دون اتصال. التطبيق لا يحتوي حالياً على نسخة محلية مدمجة من كود محرك HoloPrint، ولا ينفذ قارئ MCStructure مستقلّاً داخل Dart. واجهة CPR تلتقط تنزيلات Blob من صفحة المحرك وتحفظها من خلال نافذة Android Storage Access Framework. يجب اختبار مسار الرفع والتنزيل على جهاز Android فعلي قبل اعتبار الإصدار جاهزاً للنشر.

## المزايا الموجودة

- واجهة عربية RTL وتصميم داكن باسم CPR.
- صفحة رئيسية ومكتبة سجل الحزم والإعدادات.
- عرض محرك HoloPrint داخل التطبيق.
- اختصارات لفتح خانات استيراد MCStructure وMCWorld وMCPack.
- التقاط تنزيلات Blob الصادرة من صفحة HoloPrint ومحاولة حفظها عبر منتقي ملفات أندرويد.
- حفظ سجل الحزم محلياً باستخدام SharedPreferences.
- لا يطلب صلاحية الوصول الشامل للتخزين ولا يحتاج إلى فتح `Android/data`.
- GitHub Actions لتحليل الكود وتشغيل الاختبارات وبناء APK.

## البناء عبر GitHub Actions

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو إلى المستودع الذي تريد استخدامه.
2. افتح تبويب **Actions**.
3. اختر **Build CPR Holoprint APK**.
4. اضغط **Run workflow**.
5. بعد نجاح التنفيذ، افتح نتيجة التشغيل ونزّل artifact باسم `cpr-holoprint-apk`.

إذا لم توجد ملفات Android في المستودع، ينشئها workflow بواسطة `flutter create` قبل البناء.

## متطلبات التطوير

- Flutter stable مع Dart 3.10 أو أحدث.
- Android SDK توفره بيئة GitHub Actions.
- Android 11 أو أحدث للاختبار المستهدف.

## ما لم يتم التحقق منه بعد

- نجاح اختيار كل أنواع الملفات من داخل WebView على مختلف نسخ Android System WebView.
- اعتراض كل أساليب التنزيل التي قد يستخدمها الموقع مستقبلاً؛ جسر Blob يعتمد على آلية تنزيل الصفحة الحالية.
- استيراد الحزمة الناتجة تلقائياً إلى Minecraft. حالياً يحفظ التطبيق الملف في المكان الذي يختاره المستخدم، ثم يفتحه من مدير الملفات.
- تشغيل التحويل دون إنترنت.
- اختبار حزم ناتجة على Minecraft 1.26.52.

لا تعتبر هذه النقاط مختبرة حتى يتم تنفيذها على جهاز Android فعلي.
